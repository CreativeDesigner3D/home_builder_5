Defeito e causa raiz

"Ajustar Piso" (CONSTRUTOR) gera um piso 5 x 5 m na origem para salas feitas pelo editor de paredes ou pelo construtor, e um contorno errado (fecho convexo, face externa) para paredes da camada nova.

  1. operators/floor_builder.py:14-25 reconhece parede por btm_plane.object_kind == 'WALL', que é o padrão de todo objeto (data/properties.py:184-193): um balcão também conta.
  2. As paredes do Home Builder 5 têm a geometria só no Geometry Nodes: a malha tem 0 vértices e mesh_gen.generate_floor_from_walls não acha pontos (mesh_gen.py:136-147).
  3. Sem pontos, cai no quadrado fixo de 5 x 5 m (floor_builder.py:73-75).
  4. Com pontos (camada nova), o fecho convexo (mesh_gen.py:148, regra R-02) cobre o recorte da sala em L e passa pela face externa (área 15,06 m²).

Evidência: evidence/reproduction.md (3 casos, 3/3).

Estratégia escolhida: correção direta

Reconhecer paredes pelas marcas reais (IS_WALL_BP do Home Builder 5; btm_wall_segments da camada nova), montar o contorno pela face interna das cadeias fechadas (o mesmo princípio do "Add Floor", que já funciona), um piso por sala no mesmo objeto, sem deslocamento, e um retângulo pelas pontas das paredes só quando não houver sala fechada. Escolhida porque a causa é única e confirmada; não há hipóteses concorrentes.

Riscos e o que fica de fora

  • Risco médio: muda só o comportamento do botão "Ajustar Piso"; não toca dados salvos nem contratos; reversível pelo desfazer.
  • Fora: o padrão object_kind = 'WALL' do enum continua (mudar afeta arquivos salvos). Os outros usos dele (opening_builder.py, ui/panels.py:_scene_has_walls, walls2d/scene_io.is_other_layer_wall) ficam para correção própria (achado A012).
  • Fora: mesh_gen.generate_floor_from_walls fica como está (sem outro chamador depois da correção).
  • Fora: atualização automática deste piso pelo editor 2D (o editor atualiza os pisos IS_FLOOR_BP do "Add Floor").
  • Achado lateral (feature 003): move_over/props.py registra uma classe com o mesmo nome Python BTM_PG_InsertionPlane da classe de Object.btm_plane (data/properties.py:182). Os testes passam, mas o nome repetido deve ser trocado numa correção separada.
