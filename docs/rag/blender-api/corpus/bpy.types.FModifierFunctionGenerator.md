<a id="bpy.types.FModifierFunctionGenerator.function_type"></a>

#### bpy.types.FModifierFunctionGenerator.function_type

Type of built-in function to use (default `'SIN'`)

- `SIN`
  Sine.
- `COS`
  Cosine.
- `TAN`
  Tangent.
- `SQRT`
  Square Root.
- `LN`
  Natural Logarithm.
- `SINC`
  Normalized Sine – sin(x) / x.

**Type:**

Literal[‘SIN’, ‘COS’, ‘TAN’, ‘SQRT’, ‘LN’, ‘SINC’]
