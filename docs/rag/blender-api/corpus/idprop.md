# ID Properties Module (idprop)

This module provides access to ID property types, used for
custom properties on data-blocks, accessed via `["key"]` syntax.

- See [Custom Properties](info_quickstart.md#info-quickstart-custom-properties) for example usage.
- See [Types with Custom Property Support](bpy_types_custom_properties.md#bpy-types-custom-properties) for types that support custom properties.
