# Particle Edit Hair Brush Items

**COMB:**

Comb.

Comb hairs.

**SMOOTH:**

Smooth.

Smooth hairs.

**ADD:**

Add.

Add hairs.

**LENGTH:**

Length.

Make hairs longer or shorter.

**PUFF:**

Puff.

Make hairs stand up.

**CUT:**

Cut.

Cut hairs.

**WEIGHT:**

Weight.

Weight hair particles.
