# Object Axis Flip Items

**POS_X:**

-X to +X.

**POS_Y:**

-Y to +Y.

**POS_Z:**

-Z to +Z.

**NEG_X:**

+X to -X.

**NEG_Y:**

+Y to -Y.

**NEG_Z:**

+Z to -Z.
