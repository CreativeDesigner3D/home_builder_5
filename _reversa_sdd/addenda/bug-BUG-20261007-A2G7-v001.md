## Delta

**Antes (R-02):** "O piso deve se ajustar automaticamente ao perímetro interno delimitado pelos vértices inferiores das
paredes. Isso é computado via fecho convexo Graham Scan."

**Como deve ser lido agora:**

1. "Ajustar Piso" (`caffmob.adjust_floor`) reconhece como parede só as do Home Builder 5 (`IS_WALL_BP`, construtor e
   editor de paredes) e as da camada nova com `btm_wall_segments`. O padrão `btm_plane.object_kind = 'WALL'` não
   identifica parede.
2. O contorno de cada sala é a **face interna** das paredes, num **polígono ordenado** (aceita sala côncava, em L ou U):
   - Home Builder 5: laço fechado das origens das paredes (`find_wall_chains`). Se a espessura cai para dentro do laço,
     a face interna fica uma espessura para dentro;
   - camada nova: linha de centro dos trechos, deslocada meia espessura para dentro (cadeias de `walls2d.convert`).
3. Um piso (objeto `btm_plane.object_kind = 'FLOOR'`) com uma face por sala fechada, em coordenadas do mundo e com
   matriz identidade (ajustar de novo não desloca).
4. Sem sala fechada: retângulo pelas pontas das paredes. Sem paredes: nada é criado (aviso).
5. O fecho convexo deixa de valer para o piso; `mesh_gen.generate_floor_from_walls` fica sem chamador.
